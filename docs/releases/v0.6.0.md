- Linux as a full host: the same `run`, `list`, `devices` and `init` as on a Mac, for Android, Wear OS and the Android and desktop targets of Compose Multiplatform. iOS targets are skipped with a note.
- Linux installs: `brew install lukasanda/tap/swiftshot`, a `.deb` (Debian, Ubuntu) and an `.rpm` (Fedora, RHEL, openSUSE) on every release, besides `install.sh`. See Installation in the wiki.
- One `swiftshot.json` for both: in a Gradle project, iOS-only keys (`scheme`, `mode`, `status_bar`…) are ignored with a note, and `"frame": "appstore"` gives plain device frames.
- `--platform android` works on Linux; `--platform ios`, an Xcode project and `frame`, `calibrate`, `emit-table` say that iOS needs a Mac.
- `swiftshot init` for Compose Multiplatform: only modules with `@Preview`s, languages from `composeResources`, and `desktop_devices` / `ios_devices` when the module has those targets.
- The launcher finds a JDK 21+ in `/usr/lib/jvm` and checks the version of `java` on `PATH`; without one it names the package to install.
- The GitHub Action works on `ubuntu-latest` for Android and Compose Multiplatform projects.
