- Device frames from Apple's Product Bezels: `--frame` (plain) and `--frame appstore` (App Store size, background, localized title).
- `swiftshot frame <dir>` frames an existing screenshot folder, like `fastlane frameit`.
- Reads frameit's `Framefile.json`, `title.strings` and `keyword.strings`.
- `--frame-color`, `--framefile`, `--frame-background`, `--frame-output`, `--frame-cache`, `--accept-bezel-license`, and `frame=` in `--screen` rules.
- App Store frames are named `<name>_framed.png`, so `fastlane deliver` uploads them.
- Bezels are downloaded from Apple on first use and cached. Swiftshot does not ship them.
- `--clear` deletes only images, so `.strings` files and a `Framefile.json` in language folders stay.
- The gallery shows the framed version of each screenshot when there is one.
