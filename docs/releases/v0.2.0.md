- Device frames from Apple's Product Bezels. `--frame` puts the screenshot into the device; `--frame appstore` makes App Store-sized images with a background and a localized title.
- `swiftshot frame <dir>` frames an existing folder, like `fastlane frameit`, and reads frameit's `Framefile.json`, `title.strings` and `keyword.strings`.
- App Store frames are named `<name>_framed.png`, so `fastlane deliver` uploads them.
- Bezels are downloaded from Apple on first use. Swiftshot doesn't ship them.
- `--clear` deletes only images, so `.strings` files and a `Framefile.json` stay.
