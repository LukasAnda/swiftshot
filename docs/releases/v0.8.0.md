- Migration from Paparazzi and Roborazzi: `swiftshot init` finds their modules through the plugin, version-catalog aliases, convention plugins and test imports, without running Gradle.
- Reads each test's device exactly: Paparazzi `DeviceConfig`, Robolectric and Roborazzi qualifier strings and `robolectric.properties`. A device it can't read is reported, never guessed.
- `swiftshot.json` renders each tested preview only on its tests' devices and settings; untested previews are skipped and listed. If no test is covered, `init` writes its usual config.
- Nothing is removed from the project. Tests without a matching `@Preview`, and screenshot sizes that will differ, are listed in the output and in `swiftshot-migration.md`.
- Languages are only what the tests set, else `en-US`, with the app's other languages listed to add.
- `screens` rules with a `.` match a fully qualified function (`com.example.UiKt.Checkout`) as well as the name, and `"override_preview": true` makes a rule win over a preview's own device, size and settings.
- The first Swiftshot baseline (1.0.0) will come from CI, not from Paparazzi or Roborazzi images.
