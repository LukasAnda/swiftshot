- Migration from Paparazzi and Roborazzi: `swiftshot init` finds their modules through the plugin, version-catalog aliases, convention plugins and test imports, without running Gradle.
- Reads each test's device exactly: Paparazzi `DeviceConfig`, Robolectric and Roborazzi qualifiers, `robolectric.properties` and spec strings. A device it can't read is reported, never guessed.
- `swiftshot.json` renders each tested preview only on its tests' devices and settings; untested previews are skipped and listed.
- Nothing is removed from the project. Tests without a matching `@Preview` are listed in the output and in `swiftshot-migration.md`.
- Languages are only what the tests set, else `en-US`, with the app's other languages listed to add.
- `screens` rules match a fully qualified function (`com.example.UiKt.Checkout`) as well as the name, and `"override_preview": true` makes a rule win over a preview's own device and settings.
- The first Swiftshot baseline (1.0.0) will come from CI, not from Paparazzi or Roborazzi images.
