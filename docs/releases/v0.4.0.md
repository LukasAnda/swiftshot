- Android: Jetpack Compose `@Preview`s for phones, foldables (folded and unfolded), tablets and Wear OS, with no emulator, on a Mac or Linux. Run `swiftshot` in the folder with `gradlew`.
- Devices from Android Studio's catalog with each Pixel's camera cutout; edge-to-edge insets, status bar and gesture handle; dialogs and bottom sheets.
- `"layout": "fastlane"` writes the `fastlane supply` folders; `--frame plain` puts screenshots in Android Studio's device art.
- Linux: `install.sh` installs the Android renderer (`swiftshot-android.tar.gz`); the GitHub Action works on `ubuntu-latest`.
