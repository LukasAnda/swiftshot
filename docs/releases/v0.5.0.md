- Compose Multiplatform: `@Preview`s of a multiplatform module rendered for Android, desktop and iOS in one run. Run `swiftshot` in the folder with `gradlew`.
- Android target (also with `com.android.kotlin.multiplatform.library`): layoutlib, as for Android modules.
- Desktop target: Compose's headless `ImageComposeScene`, at 1280×800 to 1920×1080 and @2x. `--desktop-devices`; `"layout": "fastlane"` writes `desktopScreenshots`.
- iOS target: a generated SwiftUI host app rendered without booting a simulator, pixel identical to a booted one. `--ios-devices`, `--ios`. Needs a Mac with Xcode; skipped with a warning elsewhere.
- `--platforms android,desktop,ios` picks the targets.
- `Example/MultiplatformDemo`: 90 screenshots (Android phone and tablet, desktop, iPhone and iPad) in 19 s on an Apple silicon Mac.
